# Course Chart Drill

A one-page study site for memorizing the AP course chart.

1. Pick **APUSH** or **AP World**.
2. Pick how many rows (periods) the quiz covers. Those rows go blank; the rest of the chart stays filled in.
3. Answer by **typing** or by **drag & drop** from a word bank (on phones: tap a term, then tap a blank).
4. Grade **Strict** (punctuation, quotes, dashes and order must match the chart; capitals don't matter) or **Forgiving** (ignores punctuation; accepts either order within a box).

Open `index.html` in any browser. No build step and no dependencies apart from Google Fonts.

## Chart data

The chart lives in the `COURSES` object near the top of the `<script>` in `index.html`.

- **APUSH** is transcribed from the *APUSH Course Chart 2026-2027* handout.
- **AP World** is a **sample** chart built on the College Board's nine AP World History: Modern units. It did not come from a teacher. Replace it with your class's chart if yours differs.
